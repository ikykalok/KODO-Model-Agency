✦ About The Project

KŌDO is a visually expressive model agency website built around one simple idea:

Beauty has no fixed definition.

Inspired by contemporary fashion editorials, high-end photography, and modern creative studios, KŌDO presents a distinctive digital experience for discovering new talent.

With bold typography, editorial layouts, interactive photography, and a minimal color palette, the website creates a premium fashion-industry aesthetic.

Agency Locations: Paris · Milan · Tokyo · New York

Season: Spring / Summer 2027 (SS27)

---

✦ Preview & Design

The website combines editorial-inspired visuals with a clean, contemporary interface.

Design Highlights

- Minimal editorial-inspired layout.
- Bold typography using Anton.
- Elegant serif typography using Instrument Serif.
- Clean sans-serif typography using Inter.
- Signature red, black, and off-white color palette.
- Large photographic compositions.
- Smooth transitions and animation-inspired interactions.

✦ Getting Started

Follow these steps to run the project locally.

1. Clone the Repository

git clone YOUR_REPOSITORY_URL

2. Open the Project

cd KODO-MODEL-AGENCY

3. Launch the Website

Simply open "index.html" in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for a local development server.

---

✦ Customization

Change Images

Replace the images inside the "assets/" directory.

Keep the filenames consistent with the references in "index.html":

- "hero.webp" — Featured model
- "m2.webp" — Model 02
- "m3.webp" — Model 03
- "m4.webp" — Model 04
- "m5.webp" — Model 05
- "m6.webp" — Model 06

Change Colors

Edit the CSS variables inside ":root":

:root {
  --paper: #f1efea;
  --ink: #0f0f0f;
  --red: #e5242c;
}

Change Typography

The project uses:

- Anton — Display typography
- Instrument Serif — Editorial typography
- Inter — Interface typography

These fonts are loaded through Google Fonts.

✦ Design Philosophy

KŌDO is built around three principles:

INDIVIDUALITY
Every face has its own identity. No artificial categories or predefined standards.

SIMPLICITY
Minimal interfaces allow photography and typography to take center stage.

EXPRESSION
Every interaction, transition, and composition contributes to the overall visual story.
